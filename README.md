# Multilingual Machine Translator

A Google Translate-like app using Hugging Face transformers.

## Run Instructions

1. Install dependencies:
   pip install -r requirements.txt

2. Place all `.py` files in the same folder.

3. Start the app:
   python app.py

4. Open http://localhost:8501 in your browser (Streamlit UI).

## Features

- Translate text between English, Hindi, French, Spanish, German
- Auto language detection toggle
- Swap source/target languages
- Translation history
- Dark mode
- Text-to-speech output (TTS)
- Error handling
